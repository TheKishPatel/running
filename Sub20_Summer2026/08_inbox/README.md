# Inbox — Session Upload Drop Zone

Drop new session data here (Apple Watch screenshots, exports, notes).

After each session:
1. Upload the watch screenshots / data to this folder.
2. Run `/log-session` — it analyses the session, updates `training_log.csv` and
   `current_status.md`, writes a detailed breakdown to `03_session_analyses/`,
   and flags any issues.

This folder is the single drop point so nothing gets lost between turns.
